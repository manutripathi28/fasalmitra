🌾 FasalMitra

An AI farming assistant for Indian farmers, in Hindi, English and Hinglish.

FasalMitra lets a farmer describe a crop problem, get a crop recommendation, check weather-based advice, or find government schemes, by typing or by speaking. Answers come from Google's Gemini model and are written in the language the farmer used.

Why I built it

Many farmers can't easily get quick, practical advice in their own language. FasalMitra puts an agriculture assistant in the browser that understands Hindi, English and Hinglish (Hindi written in Roman script), and accepts voice input so farmers don't have to type.

Features
Feature	What it does
🌿 Crop problem diagnosis	Describe a problem (e.g. "mere tamatar ke patte peele ho rahe hain") and get likely causes and remedies
🌱 Best crop suggestion	Choose state, season (Kharif / Rabi / Zaid), soil type and land size to get crop recommendations
☀️ Weather advice	Enter a city and get farming advice for the season there
🏛️ Government scheme finder	Enter your details and get relevant schemes (PM-KISAN, crop insurance, Soil Health Card, etc.)
🎙️ Voice input	Speak your question instead of typing (Hindi speech recognition)
🧭 Voice navigation	A floating voice assistant that can move you between pages
🌐 Multilingual replies	Detects Hindi / English / Hinglish from the question, or pick a language manually
🕘 History	Past questions and answers are saved in your browser
📱 Responsive	Bottom navigation on mobile, full navbar on desktop
Tech stack
Frontend: React 19 (Create React App)
AI: Google Gemini API (gemini-2.5-flash) via REST
Voice: Web Speech API (SpeechRecognition)
Storage: Browser localStorage for history
Testing setup: Jest + React Testing Library
Getting started
Prerequisites
Node.js 18+ and npm
A free Gemini API key from Google AI Studio
Installation
bash
# 1. Clone the repository
git clone https://github.com/manutripathi28/fasalmitra.git
cd fasalmitra

# 2. Install dependencies
npm install
Add your API key

Use either option:

Option A: .env file

bash
cp .env.example .env
# then edit .env and set:
# REACT_APP_GEMINI_API_KEY=your_gemini_api_key_here

Option B: public/config.js

bash
cp public/config.example.js public/config.js
# then edit public/config.js and set GEMINI_API_KEY

Both files are git-ignored, so your key won't be committed.

Run the app
bash
npm start

The app opens at http://localhost:3000. Restart the dev server after changing .env.

Other scripts
bash
npm run build   # production build
npm test        # run tests
How it works
The farmer types or speaks a question (voice uses the browser's speech recognition set to Hindi).
The app detects the language (Hindi, English or Hinglish) and builds a prompt with the farmer's details.
The prompt is sent to Gemini, and the reply is shown in a readable card in the same language.
The question and answer are saved to history in localStorage.

Limitations
API key is used in the browser. In this version the key ships to the client, so anyone can find it in the browser. Use a restricted key for local use. Don't deploy publicly with an unrestricted one.
Weather advice is not live data. It is generated by the AI model from typical seasonal patterns for the city, not from a real-time weather service.
AI answers can be wrong. Treat suggestions as guidance and confirm with a local agriculture officer before applying chemicals or making big decisions.
Voice input depends on browser support (works best in Chrome).
Everything lives in one large App.jsx file.
